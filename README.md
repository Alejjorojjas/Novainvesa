# Novainvesa

Tienda de dropshipping multi-categoría para Colombia y LATAM.

## Stack
- **Frontend:** React + Vite + Tailwind CSS → Hostinger
- **Backend:** Node.js + Express → Render.com
- **Base de datos:** MySQL → Hostinger
- **Proveedor:** Dropi
- **Pagos:** Wompi + MercadoPago + COD
- **WhatsApp Bot:** Chatea Pro
